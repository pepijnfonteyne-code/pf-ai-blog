Gisteren onthulde Google op I/O 2026 Gemini Omni: één model dat text, image, audio en video tegelijk verwerkt én genereert binnen één API-call. Tegelijkertijd publiceerde NVIDIA een technische deep-dive over Hermes van NousResearch — inmiddels het meest gebruikte AI-agent op OpenRouter — met als kernfeature dat het zijn eigen skill-bestanden schrijft en verfijnt. En OpenAI verving zijn standaardmodel met GPT-5.5 Instant, waarbij interne benchmarks 52,5% minder gehallucineerde claims laten zien op high-stakes domeinvragen.

Drie bewegingen die ogenschijnlijk niets met elkaar te maken hebben, maar samen een patroon tonen: modellen worden meer unified, agents worden meer autonoom, en accuraatheid verschuift van vage belofte naar meetbare specificatie-eis.

## Gemini — Omni any-to-any en 3.5 Flash als agentic flagship

Google introduceerde Gemini Omni als architecturele breuk met de vorige aanpak. Waar je eerder drie separate systemen moest orkestreren — Gemini 3.1 voor reasoning, Veo 3.1 voor video, Imagen 4.0 voor images — valt dit nu samen in één model met gedeelde interne representaties over alle modaliteiten. Je kunt image-input en text-input combineren zonder expliciete context-bridging in je orchestratie; het model houdt intern consistente state bij over modality-grenzen heen.

Omni Flash, de lichte variant uitgerold op 19 mei, is momenteel gecapped op 10 seconden video-output per API-call. Dit is een deployment constraint, geen technische beperking van het model zelf. API access staat voor de komende weken ingepland; interne schattingen draaien rond $0,10–0,50 per seconde video-output afhankelijk van resolutie.

Naast Omni introduceerde Google Gemini 3.5 Flash als het nieuwe agentic flagship — bedoeld voor multi-step reasoning tasks waar je nu Claude Opus 4.7 inzet. De benchmarks zijn interessant genoeg dat directe vergelijking met je bestaande pipelines de moeite waard is zodra de API beschikbaar is. Als context: Gemini 3 Deep Think scoorde gold medal op de International Physics en Chemistry Olympiad 2025 — niet bijzonder nuttig voor productie, maar het illustreert dat de kloof tussen top-models en menselijke experts in formeel redeneren vrijwel gedicht is.

De unified multimodal architectuur van Omni is ook architectureel interessant als alternatief voor multi-model orchestratie: één API-call voor een pipeline die voorheen drie modellen in serie nodig had.

## Hermes / Open Source — Zelf-schrijvende agents op DGX Spark

NousResearch's Hermes groeide in drie maanden naar meer dan 140k GitHub stars en staat momenteel op #1 op OpenRouter qua gebruik. NVIDIA publiceerde een uitgebreide technische post met als focus één concrete feature: Hermes schrijft en verfijnt zijn eigen skill-bestanden tijdens gebruik.

De self-improvement loop werkt als volgt: bij het uitvoeren van een taak genereert Hermes een Python skill-file die de functie implementeert die het net heeft opgelost. Bij een volgende vergelijkbare taak laadt het dezelfde skill opnieuw in plaats van opnieuw te genereren. Over meerdere runs accumuleert een bibliotheek van verfijnde, herbruikbare functies die het model van sessie tot sessie effectiever maken.

```python
# Voorbeeld van een door Hermes gegenereerde skill-file
# skills/fetch_json_paginated.py
def fetch_json_paginated(url: str, headers: dict, max_pages: int = 10) -> list:
    results = []
    page = 1
    while page <= max_pages:
        resp = requests.get(f"{url}?page={page}", headers=headers)
        data = resp.json()
        if not data.get("items"):
            break
        results.extend(data["items"])
        page += 1
    return results
```

De hardware-context: NVIDIA DGX Spark (1 petaFLOP FP4, 128 GB unified memory via GB10 Grace Blackwell Superchip) maakt het mogelijk Qwen 3.6 27B of 35B lokaal te draaien. Dat zijn modellen die vorige-generatie 120B–400B architecturen overtreffen op agentic benchmarks. Tot 4 nodes kunnen via RoCE worden samengevoegd voor modellen tot 700B parameters.

Hermes biedt een OpenAI/Anthropic-compatibele API, wat directe integratie in bestaande Claude Code workflows mogelijk maakt. De skill-writing architectuur is een interessante designrichting voor Orion: in plaats van statische tool-definities, laat je een agent zijn eigen tool-library opbouwen op basis van taken die het succesvol heeft afgerond. Het is een concrete invulling van "lerende agent" die niet afhankelijk is van fine-tuning of model-updates.

## OpenAI — GPT-5.5 Instant en de 52,5% benchmark

OpenAI verving GPT-5.3 Instant als standaardmodel voor ChatGPT met GPT-5.5 Instant. Het meest geciteerde getal uit de aankondiging: 52,5% reductie in gehallucineerde claims op high-stakes prompts in geneeskunde, recht en financiën — gemeten via interne evaluaties.

Dat getal verdient nuancering. "Interne evaluaties" is geen open benchmark, en hallucinatiefrequentie is sterk domein- en prompt-afhankelijk. Maar de richting is consistent met wat praktijkgebruikers de afgelopen maanden rapporteren: GPT-5.x gedraagt zich beduidend factuerder dan GPT-4.x bij precisie-taken op specifieke domeinen.

GPT-5.3 Instant blijft beschikbaar voor paid users gedurende drie maanden via model configuration — genoeg ruimte om gecontroleerd te migreren als je de versie pinned in je applicatie of CI pipeline.

Op 15 mei volgde ook een Personal Finance feature voor Pro-users in de VS: secure account connections via OAuth/banking API integratie, spending tracking en een money dashboard. Technisch minder interessant, maar het illustreert hoe ChatGPT zich als platform positioneert voor domein-specifieke verticalen naast pure model-API access. De sidebar-architectuur van ChatGPT for Excel/Sheets (nu globaal beschikbaar) is ook een interessant referentieontwerp voor eigen spreadsheet-integraties.

## Claude Code — Code w/ Claude 2026 en de nieuwe agent flags

Begin mei hield Anthropic de Code w/ Claude developer conference. Twee concrete wijzigingen: rate limits voor Claude Code Pro/Max/Enterprise werden verdubbeld — de 5-uur limiet 2x verhoogd — en Opus API-limieten gingen omhoog. Relevant als je langere agentic runs draait of meerdere parallelle sessions beheert.

De conference bevestigde ook het partnerschap met SpaceX voor volledige benutting van het Colossus datacenter (100k H100-cluster in Memphis) — een aanwijzing voor significante inferentiecapaciteitsgroei de komende maanden. API-volume groeide het afgelopen jaar 17x jaar-op-jaar. Fast Mode draait nu standaard op Opus 4.7 in plaats van 4.6.

Minder zichtbaar maar technisch relevanter zijn de nieuwe agent flags voor background sessions:

```bash
claude \
  --add-dir /path/to/extra/context \
  --settings custom-settings.json \
  --mcp-config project-mcp.json \
  --plugin-dir ./plugins \
  --permission-mode default-allow \
  --model claude-opus-4-7 \
  --effort high \
  /path/to/task.md
```

Met `--mcp-config` geef je per sub-agent een aparte MCP-configuratie mee — essentieel als je agents met verschillende tool-sets wilt isoleren in een gelaagde pipeline. `--permission-mode default-allow` schakelt interactieve confirmations uit voor achtergrondprocessen. `--effort high` stuurt de hoeveelheid intern redeneerwerk van het model, vergelijkbaar met de thinking-budget in de API.

## Open Source Tools — CLI-Anything: elke CLI automatisch agent-native

CLI-Anything van HKUDS (38,5k GitHub stars, +4k deze week) pakt een concreet probleem aan: de meeste bestaande CLI-tools zijn slecht bruikbaar door AI-agents omdat er geen structured discovery bestaat. De tool genereert automatisch een agent-native interface voor elke CLI via een 7-fase pipeline (analyse → design → implementatie → testing → validatie).

Het resultaat per CLI is een `SKILL.md` bestand met naam, beschrijving, command groups, usage examples en agent-instructies. Claude Code kan deze structuur automatisch inladen voor tool discovery zonder menselijke documentatie of expliciete tool-routing.

```bash
pip install cli-anything-hub

# Bestaande CLI agent-native maken
cli-anything convert --tool restic --output ./skills/
# Genereert: skills/restic/SKILL.md + typed CLI wrapper

# Installeer community skills via CLI-Hub
cli-anything-hub install git-advanced
cli-anything-hub install docker-agent
```

Native support voor Claude Code, Codex, Goose, Qoder, en GitHub Copilot CLI. De pipeline scoorde 100% pass rate over 1.917 tests op 19 applicaties.

Directe toepassing: gebruik CLI-Anything om interne scripts en tools in Orion agent-native te maken. De SKILL.md standaard is ook een goed format om over te nemen voor eigen tool-documentatie in Claude Code projects — het geeft agents genoeg structuur voor autonomous tool selection zonder dat je expliciete routing-logica hoeft te implementeren.

## Tot slot

Simon Willison schreef op 19 mei een beknopte synthesis van zes maanden LLM-ontwikkeling. Zijn kernobservatie: de combinatie van "context windows die aanvoelen als oneindig" met high-quality memory verandert architectuurkeuzes kwalitatief — niet gradueel. Je vervangt state machines en workflow-engines. De bottleneck in multi-agent systemen zit niet meer in model-capaciteit maar in orchestration design en evaluation kwaliteit.

Dat verklaart waarom CLI-Anything's SKILL.md standaard, Hermes' skill-writing loop, en Claude Code's `--mcp-config` flags allemaal dezelfde kant op wijzen: de infrastructuur voor gelaagde, zelf-beschrijvende agent-architecturen is volwassen aan het worden. Niet als abstract idee, maar als concrete tooling die je vandaag kunt installeren en testen.
