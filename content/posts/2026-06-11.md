Drie bewegingen die de frontier-markt deze week herstructureren: Anthropic introduceert een nieuwe modelklasse boven Opus, Apple maakt zijn platform-keuze voor Siri expliciet via een licentie-plus-private-hosting-architectuur, en Microsoft bevestigt dat het OpenAI niet langer als enige modelbron ziet.

Elk van deze ontwikkelingen heeft directe implicaties voor hoe we multi-model pipelines en agentic infra bouwen — meer dan de meeste incrementele updates van de voorbije weken.

## Claude Code — Fable 5: eerste publieke Mythos-class model

Anthropic lanceerde op 9 juni Claude Fable 5 — het eerste publiek beschikbare model in de nieuwe Mythos-tier, een laag boven de bestaande Opus-lijn. Simon Willison testte het 5,5 uur en kwalificeerde het als "slow, expensive" maar uitzonderlijk capabel. Onafhankelijke evals rapporteren ~80% op SWE-Bench Pro.

Pricing: $10/$50 per miljoen input/output tokens — exact dubbel ten opzichte van Opus 4.8 ($5/$25).

**Wanneer Fable 5, wanneer Opus 4.8?**

De kostenverhouding is helder genoeg voor een duidelijke vuistregel:

- **Fable 5**: complexe codebase-migraties, deep reasoning chains (>10 stappen), judge-model in multi-agent setups, taken waarbij een fout op planningsniveau de hele pipeline blokkeert.
- **Opus 4.8**: dagelijkse coding-assist, iteratief debuggen, taken waar latency en kosten meer tellen dan maximale redeneerdiepte.

In Claude Code is Fable 5 beschikbaar via modelkeuze. Het is niet de nieuwe default — Opus 4.8 blijft default op Max-, Team- en Enterprise-accounts.

**Project Glasswing**

Naast de publieke Fable 5 bestaat er een aparte variant — Claude Mythos 5 — zonder de standaard safeguards. Die is exclusief toegankelijk via Project Glasswing voor vetted infra-providers en cybersecurity researchers. Relevant als je werkt aan offensieve security research of infrastructuurplatforms die de ruimere API-grenzen nodig hebben.

**Fable 5 als orchestrator in Dynamic Workflows**

Met Dynamic Workflows (geïntroduceerd in Claude Code Week 22) is het nuttig om Fable 5 in te zetten als top-level orchestrator die een orchestratiescript schrijft terwijl Opus 4.8 de uitvoerende subagents draait. Zo betaal je de Fable 5-prijs alleen voor de kleinste maar meest beslissende stap — planning en redeneren — en Opus 4.8 voor de uitvoering:

```yaml
# claude-code-config.yaml (hypothetisch)
orchestrator_model: claude-fable-5
subagent_model: claude-opus-4-8
max_parallel_agents: 12
effort: xhigh
```

Dit patroon maakt de dubbele prijs van Fable 5 rationeel: je inzet is gericht op het deel van de taak waar het werkelijk uitmaakt.

## AI Builders — Apple en het 'licentie + private hosting'-patroon

Op WWDC 2026 bevestigde Apple dat de nieuwe Siri AI-features draaien op een Gemini-afgeleid model via Private Cloud Compute (PCC). Apple heeft de Gemini-architectuur onder licentie, maar host alle inferentie zelf in eigen beveiligde cloud-infra — volledig los van Google's servers.

Simon Willison beschreef het als het meest interessante architectuurgeheim van WWDC: je neemt frontier model-capaciteit (via licentie), maar behoudt volledige controle over het inferentiepad voor privacy en compliance.

**Wat het PCC-design concreet doet**

- On-device vs. cloud-balancing blijft behouden: lichte taken draaien op Apple Silicon NPU; zware requests gaan naar PCC.
- PCC isoleert inferentie van Apple's reguliere cloud — aparte hardware, geattesteerde software-stack, geen logging naar Apple-systemen buiten PCC.
- Het Gemini-derived model heeft Apple's eigen safety- en privacy-layers — niet Google's standaard Gemini-safeguards. Apple heeft het model post-training aangepast.

**Relevantie als architectuurpatroon**

Als Orion ooit richting enterprise-klanten gaat met harde data-residency eisen (GDPR-artikel 44, SOC2 Type II, banking regulations), is het Apple-patroon een bruikbaar template: licentie het capacabelste frontier model beschikbaar, bouw je eigen inference-infra op dedicated hardware, en attesteer die stack met een transparantieraamwerk. Apple bewijst dat frontier labs dit bedrijfsmodel accepteren op grote schaal.

Het impliceert ook dat Apple niet gebonden is aan één model-provider. Als Google's architectuur niet meer de sterkste is over twee jaar, kan Apple overstappen met minimale infrastructuurwijzigingen — de infra-laag (PCC) blijft stabiel, alleen de model-weights wisselen.

## OpenAI-ecosysteem — Microsoft lanceert eigen MAI-Thinking-1 en MAI-Code-1-Flash

Microsoft kondigde twee eigen frontier LLMs aan die los staan van OpenAI: MAI-Thinking-1 en MAI-Code-1-Flash. Dit markeert een strategische verschuiving — Microsoft bouwt nu parallel aan OpenAI's modellen in plaats van uitsluitend te resellen of te wrappen.

**Architectuur**

- **MAI-Thinking-1**: sparse Mixture-of-Experts, 1T parameters totaal / 35B actief, geoptimaliseerd voor diepe reasoning chains. Vergelijkbaar qua opzet met GPT-4o's MoE-architectuur maar met meer aandacht voor lange inference-ketens.
- **MAI-Code-1-Flash**: 137B parameters totaal / 5B actief, ultra-lage latency voor code completion. Dit is nu de inference backbone van GitHub Copilot — niet langer uitsluitend OpenAI-modellen.

De MoE-ratio's zijn opvallend: 5B actief op 137B totaal is agressiever dan wat de meeste labs publiceren. Dat wijst op een sterk gespecialiseerde routing die ten koste gaat van generalisme maar wint op snelheid en kosten bij code-domeinspecifieke taken.

**MAI-Code-1-Flash via Copilot API**

MAI-Code-1-Flash is beschikbaar via de GitHub Copilot API. Voor lage-latency code-assist integraties is dit een optie die mogelijk goedkoper uitkomt dan OpenAI's gpt-4o-mini of Anthropic's Haiku 4.5 — afhankelijk van je GitHub Enterprise-licentie:

```bash
# Copilot API endpoint voor MAI-Code-1-Flash (preview)
POST https://api.githubcopilot.com/chat/completions
Authorization: Bearer $GITHUB_TOKEN
Content-Type: application/json
# Body: { "model": "mai-code-1-flash", "messages": [...] }
```

**Strategische implicatie voor multi-model setups**

Microsoft heeft nu een eigen modellenlijn op Azure. Een multi-model pipeline op Azure-infra kan straks naadloos schakelen tussen OpenAI GPT-modellen, Anthropic Claude (via Azure AI Foundry), en Microsoft's eigen MAI-serie — zonder provider-lock-in op model-niveau. Als je Azure als deployment-target overweegt voor Orion, is de MAI-serie de derde as naast OpenAI en Anthropic.

## Tot slot

Fable 5 kost twee keer zoveel als Opus 4.8 per token, en toch is de interessante vraag niet "is het de prijs waard?" maar "op welk niveau in de pipeline zet je het in?" Als je Dynamic Workflows gebruikt als orchestrator-laag, betaal je de Fable 5-prijs alleen voor planning en redeneren — de stap waar capaciteit het meest uitmaakt. De uitvoering draait op Opus 4.8. Dat patroon maakt de kostenstructuur rationeel, en het is waarschijnlijk precies het gebruik-patroon dat Anthropic in gedachten had bij de Mythos-tier pricing.
