## Claude Code — Agent View, Opus 4.8 en verdubbelde rate limits

De meest opvallende toevoeging is `claude agents`: een nieuw subcommando dat alle actieve Claude Code sessies als rijen toont in een live-updating dashboard. Elke rij bevat status, laatste respons en timestamp — je hoeft niet langer in de shell van een individuele sessie te springen om te zien wat er gebeurt.

```bash
claude agents               # overzicht alle actieve sessies
claude agents --json --all  # machine-readable output met id en state velden
```

De `--json --all` flag is de relevante toevoeging voor programmatisch gebruik: scripts in CI/CD-pipelines kunnen hiermee de toestand van lopende agents pollen zonder een apart process management layer. Je kunt zo meerdere Claude Code instanties dispatchen naar verschillende branches of subtaken en ze centraal monitoren.

Tegelijk is Opus 4.8 het nieuwe standaardmodel in Claude Code voor taken die de volledige reasoning kracht nodig hebben. Dat is een stille upgrade: je configureert niets, het model wordt automatisch geselecteerd op basis van taakcomplexiteit. De rate limits zijn verdubbeld ten opzichte van de vorige periode — relevant als je meerdere parallelle agent-sessies draait die elk API calls genereren.

De derde toevoeging is `/usage breakdown`: een inline overzicht dat per plugin-component het tokenverbruik laat zien. Combineer dit met een context compressor in je MCP stack voor een volledige cost-attribution loop: je ziet precies welke component de meeste tokens eet en je comprimeert die input gericht.

## OpenAI — ChatGPT wordt super app: 90+ plugins, per-minuut billing

OpenAI is middenin de grootste ChatGPT overhaul ooit. De richting: ChatGPT als platform waarop Jira, Microsoft 365, Notion, Slack en 90+ andere tools als native agents draaien — niet als externe integraties maar als first-class participants in de conversatie.

Dat is een directe tegenhanger van de MCP-benadering, maar dan in gesloten ecosysteem. Waar MCP een open protocol is dat elke server kan implementeren, bouwen ze bij OpenAI een plugin marketplace die centraal beheerd is. Beide benaderingen lossen hetzelfde probleem op (AI die tools gebruikt), maar de governance is fundamenteel anders: open federatie vs. curated platform.

Concreet verandert ook het billing model voor container sessions. Waar container gebruik eerder gefactureerd werd per vaste blok van 20 minuten, is dat nu per minuut met een minimum van 5 minuten. Voor kortlopende subtasks die toevallig net in een 20-minuten blok vielen, is dat een voordeel. Voor langlopende agentic workflows die continu een container bezetten, maakt het weinig verschil.

GPT-5.5 Instant, de base voor Codex en Operator, rollede in juni verbeterde personalisatie uit en kortere, meer gerichte antwoorden. Codex groeide naar 4 miljoen weekly developers via GPT-5.5 als agentic-first base model met parallel worker sub-agents en cloud sandbox execution. GPT-4.5 wordt 27 juni retired.

## Open Source Tools — Strava MCP als referentie voor remote OAuth integraties

Strava heeft op 1 juni een officiële remote MCP server gelanceerd die subscribers toegang geeft tot hun trainingsdata vanuit Claude.ai, Claude Desktop en Claude Code. Read-only, scoped aan het eigen account, intrekkend via Strava settings. Toegang via een standaard OAuth flow.

De technische inhoud van de Strava-data zelf (HR streams, GPS routes, cycling power) is voor dit publiek minder interessant dan de architectuur: dit is hoe een grote consumer API een production-grade MCP server inricht. De kenmerken:

- **Remote server**: draait bij Strava, niet lokaal geïnstalleerd
- **OAuth authenticatie**: standaard OAuth flow, geen API keys die je beheert
- **Read-only scope**: strikt minimale permissies
- **Revocable via provider UI**: gebruiker trekt toegang in via eigen instellingen, niet via de MCP client

```yaml
# claude_desktop_config.json / mcp.json
mcpServers:
  strava:
    url: "https://mcp.strava.com"
    transport: "http"
    auth:
      type: "oauth"
```

Dit is het patroon voor enterprise MCP integraties: geen gedeelde credentials, geen lokale state, permissies beheerd door de resource server. Als je eigen remote MCP servers bouwt voor klanten of interne teams, is het Strava MCP een concrete referentie-implementatie om naar te kijken. Strava is partner van Anthropic en plant uitbreiding naar andere AI clients — het is de eerste grote consumer API die dit pad bewandelt.

## AI Builders — Graduate Workflow en de Code Review paradigmaverschuiving

Claude Code scoort 80.8% op SWE-bench Verified en staat daarmee bovenaan bij professional engineers. Wat meer zegt over hoe het gebruikt wordt: het dominante patroon heet het **Graduate Workflow**.

De flow is tweestaps:
1. **Prototyping**: browser-based tools (Bolt, Lovable) voor snelle UI-skeletons en viability checks
2. **Refinement**: Claude Code voor productie-kwaliteit refactoring, multi-file patches en codebase-brede wijzigingen

De verschuiving die hiermee samenhangt is van *Code Generation* naar *Code Review*: AI schrijft complete feature drafts en patches voor meerdere bestanden tegelijk, de developer reviewt en stuurt bij. De cognitieve last verschuift van schrijven naar beoordelen — wat andere vaardigheden activeert maar niet noodzakelijk minder werk betekent bij complexe features.

Dify voor workflow orchestration en Firecrawl voor data ingestion verschijnen regelmatig naast Claude Code in beschreven stacks voor juni 2026. De combinatie Dify (orchestration) + Claude Code (uitvoering) + Firecrawl (web data) lost drie stukken van een typische agentic pipeline op zonder dat je elk stuk zelf bouwt. AI workflow builders evolueren naar intelligent orchestration platforms met reasoning en adaptive execution — waar hardcoded pipelines vroeger voldoende waren, verwacht je nu dat het systeem zelf routes kiest op basis van tussentijdse output.

De 80.8% SWE-bench score is relevant als selectiecriterium in multi-model pipelines: voor complexe multi-file coding subtasks blijft Claude Code de sterkste keuze. Goedkopere modellen kunnen scouting, summarization en routing voor hun rekening nemen; de zware codechanges gaan naar Opus 4.8 via Claude Code.
