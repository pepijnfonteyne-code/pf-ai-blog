De agentic stapel wordt volwassener: Claude Code krijgt recursieve orchestratie tot vijf niveaus diep, het OpenAI-ecosysteem ruimt model IDs op met een harde cutoff, Gemini 3.5 Flash positioneert zich als kostenefficiënt alternatief voor tool-heavy workloads, en Hermes krijgt een native desktop app die het als open-source agent platform serieus neemt.

Vier updates met directe implicaties voor hoe je agent workflows bouwt en welke model IDs je in productie gebruikt.

## Claude Code — Recursieve sub-agents tot 5 niveaus diep

Claude Code v2.1.172 (uitgebracht op 10 juni) introduceert een architecturele uitbreiding die interessant is voor complexe fan-out workflows: sub-agents mogen nu hun eigen sub-agents spawnen, recursief tot 5 niveaus diep.

In de praktijk betekent dit dat je een orchestrator-agent kunt bouwen die specialist-subagents delegeert, die elk op hun beurt verdere decomposities kunnen uitvoeren:

```
orchestrator (niveau 1)
├── code-review-agent (niveau 2)
│   ├── security-scanner (niveau 3)
│   └── style-checker (niveau 3)
├── test-runner-agent (niveau 2)
│   └── coverage-analyzer (niveau 3)
└── docs-agent (niveau 2)
    ├── api-extractor (niveau 3)
    └── example-generator (niveau 3)
```

Elke node in deze boom heeft toegang tot de volledige toolset. De implicaties voor Orion-workflows zijn concreet: taken die nu als sequentiële chain lopen kunnen worden omgebouwd naar een hiërarchische verdeling waarbij parallelle branches pas terugkoppelen naar de orchestrator als ze klaar zijn.

Het 5-niveaus-limiet is bewust. Diepere recursie zonder output-bounds op elke node leidde in testing tot ongecontroleerde token explosie. De aanbeveling in de changelog is elk sub-agent niveau te begrenzen met een expliciete output scope — anders eet de boomstructuur snel je context op.

Relevant detail: `ultracode` (hernoemd van `workflow` in v2.1.160) stuurt `xhigh` effort en orkestreert dynamische multi-agent workflows automatisch voor substantiële taken. Nested sub-agents en ultracode werken complementair — ultracode bepaalt wanneer decomposie zinvol is, de nested architectuur bepaalt hoe diep die decomposie gaat.

## OpenAI — GPT-5.2 end-of-life, GPT-5.5 Instant is nu default

Per 12 juni 2026 is de volledige GPT-5.2 familie uit de API verwijderd. De model IDs `gpt-5.2-instant`, `gpt-5.2-thinking` en `gpt-5.2-pro` retourneren nu een 404. Bestaande ChatGPT-gesprekken zijn automatisch gemigreerd naar hun GPT-5.5 equivalenten; API-integraties moeten handmatig worden bijgewerkt.

GPT-5.5 Instant is nu het standaardmodel in ChatGPT. De voornaamste verbeteringen ten opzichte van GPT-5.2 Instant zijn beknoptere antwoorden (minder padding) en verbeterde personalisatie, uitgerold naar Free- en Go-plans per 9 juni. GPT-5.6 is in ontwikkeling met een verwacht 1.5M context window en verbeterde agentic capabilities — geen releasedatum.

Migratiematrix:

| Oud model ID | Nieuw model ID |
|---|---|
| `gpt-5.2-instant` | `gpt-5.5-instant` |
| `gpt-5.2-thinking` | `gpt-5.5-thinking` |
| `gpt-5.2-pro` | `gpt-5.5-pro` |
| `gpt-4.5` | `gpt-5.5-instant` (of hoger) |

De volgende deadline: **GPT-4.5 wordt deprecated per 27 juni.** Nog GPT-4.5 calls in productie? Zet die om voor volgende week — dat is negen dagen.

## Gemini — 3.5 Flash GA met 83.6% op MCP Atlas

Gemini 3.5 Flash is GA als Google's primaire model voor agentic en coding workloads. Model ID: `gemini-3.5-flash` (stable, beschikbaar in global/US/EU Gemini Enterprise).

De interessante benchmark is MCP Atlas (tool-use): **83.6%**. Voor agentic workflows waarbij de kwaliteit van tool selection en tool-call correctheid bepalend is, is dat een serieuze score. Terminal-Bench 2.1 geeft 76.2% — een stap omhoog ten opzichte van Gemini 3.1 Pro's 70.3% op hetzelfde benchmark.

De pricing maakt het interessant als alternatief voor Claude Sonnet in MCP-heavy pipelines:
- Input: $1.50/M tokens
- Output: $9/M tokens
- Gecachede input: $0.15/M (**90% korting**)

Voor repetitieve agentic patterns waarbij dezelfde system prompt of grote context hergebruikt wordt, is dat cache-voordeel significant. Een orchestrator die honderd tool-calls maakt op dezelfde context kan 90% van de input-kosten terugwinnen.

GDPval-AA Elo van 1656 positioneert het als serieuze concurrent voor economisch waardevolle agentic work. Gemini 3.5 Pro wordt verwacht later in juni. Als die er is, is het vergelijkingspunt met Claude Sonnet relevanter dan nu met Flash.

Voor migratie-evaluatie: Google AI Studio biedt side-by-side vergelijking. Test specifiek op jullie MCP-tool patterns — de MCP Atlas score is een gemiddelde, niet een garantie op jullie specifieke tools.

## Hermes/Open Source — Desktop app, MCP catalog en Skills Hub

Hermes Agent v0.16.0 "The Surface Release" (5 juni) is een significante release voor het open-source agent ecosysteem: 874 commits, 542 merged PRs, 1962 bestanden gewijzigd, 170 contributors.

De grootste toevoeging is een **native Electron desktop app** voor macOS, Linux en Windows. One-click install, in-app self-update, Cmd+K command palette en drag-and-drop bestanden. Concurrent multi-profile sessions zijn mogelijk — meerdere agent-configuraties naast elkaar. Voor wie Hermes als self-hosted agent platform overweegt verlaagt dit de drempel significant.

Architectureel interessant is de combinatie van de browser-based admin panel met MCP catalog en de NVIDIA Skills Hub integratie. De admin panel regelt MCP servers, messaging channels, credentials, webhooks en memory vanuit één interface. De Skills Hub biedt een gecureerde set van verified skills als one-click installaties, inclusief NVIDIA-integraties. OAuth en username/password remote gateway zijn beschikbaar voor team deployments.

Security fixes in deze release: CVE-2026-48710 (Starlette pin), SSRF hardening en subprocess credential stripping.

Als referentie-implementatie voor agent UI patronen is Hermes Desktop nu de meest complete open-source optie beschikbaar. De MCP catalog architectuur — hoe je servers beheert, vertrouwt en versieert — is een bruikbaar patroon voor eigen Orion tooling.
