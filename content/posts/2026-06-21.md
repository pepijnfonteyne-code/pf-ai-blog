De week van 21 juni markeert een stille maar betekenisvolle verschuiving: Claude Code levert infrastructuur-features die monorepo- en enterprise-workflows grondig veranderen, terwijl buiten Anthropic de rekening van intensief AI-gebruik zichtbaar wordt. Geen spectaculaire modellaunch deze keer — wel het soort updates dat je werkdag hervormt.

Ondertussen passeert het MCP-ecosysteem de 10.000 publieke servers, en dat brengt een architectural reckoning met zich mee: hoe feed je een agent 10K tools zonder context te exploderen?

## Claude Code Week 24 — /cd, --safe-mode en fallbackModel chains

Claude Code v2.1.169–172 introduceert drie features die los van elkaar klein lijken maar samen een ander werkpatroon mogelijk maken.

**`/cd` voor mid-sessie directory-switches**

Tot nu toe betekende van project wisselen tijdens een sessie: nieuwe sessie starten, prompt-cache herbouwen, CLAUDE.md opnieuw laden. `/cd <pad>` doet het anders: de nieuwe CLAUDE.md wordt als conversatiebericht in de actieve thread geïnjecteerd in plaats van de systeemprompt te vervangen. De cache blijft intact.

In een monorepo-context — stel een repo met `/backend`, `/frontend` en `/infra` als aparte projecten elk met hun eigen CLAUDE.md — kun je nu in één sessie door alle drie navigeren zonder keer op keer opnieuw op te starten. De context accumuleert in plaats van te resetten.

```bash
# Monorepo workflow
/cd ./backend        # CLAUDE.md van backend als bericht toegevoegd
# ... werk aan API
/cd ./frontend       # CLAUDE.md van frontend als bericht toegevoegd
# ... werk aan UI
/cd ./infra          # CLAUDE.md van infra als bericht toegevoegd
```

Technisch detail: de sessie wordt verplaatst naar de project storage van de nieuwe directory, maar de message history blijft intact. Dat is fundamenteel anders dan een nieuwe sessie: de agent weet nog wat je vorige project deed.

**`--safe-mode` voor config-isolatie**

`--safe-mode` (of `CLAUDE_CODE_SAFE_MODE=true`) start Claude Code met alle customisaties uitgeschakeld: geen CLAUDE.md, geen skills, geen plugins, geen hooks, geen MCP servers, geen custom commands. Bedoeld als debug-tool wanneer een gebroken hook of plugin de sessie blokkeert.

Dit is de equivalent van Chrome's incognito-mode voor Claude Code: je weet zeker dat het gedrag dat je observeert van het model komt, niet van een skill die je een maand geleden hebt geïnstalleerd en sindsdien niet meer hebt aangeraakt.

```bash
CLAUDE_CODE_SAFE_MODE=true claude
# of
claude --safe-mode
```

**fallbackModel chains**

De nieuwe `fallbackModel` configuratie laat je tot drie terugvalmodellen instellen in volgorde, bij overload of unavailability. Relevant voor productie-setups met hoge throughput, of voor teams die Fable 5 als primary willen maar naar Opus 4.8 willen terugvallen bij capacity limits.

```json
{
  "model": "claude-fable-5",
  "fallbackModel": ["claude-opus-4-8", "claude-sonnet-4-6"]
}
```

Gecombineerd met de auto mode op Bedrock/Vertex (Week 23) en recursieve sub-agents (ook Week 24) geeft dit enterprise deployments granulaire controle over model-routing zonder externe load balancers te hoeven schrijven.

## MCP-ecosysteem — 10.000 servers, Tool Search en stateless HTTP-roadmap

Het MCP-ecosysteem telt nu meer dan 10.000 actieve publieke servers en 97 miljoen SDK-downloads per maand (Python + TypeScript gecombineerd). Dat zijn imposante cijfers — maar ze brengen een architecturaal probleem mee.

**Het tool-lijst probleem**

Je kunt geen 10.000 servers aan een model meegeven. Zelfs een subset van 50–100 servers met elk 5–20 tools geeft een tool-lijst die snel de context domineert en inference vertraagt. Anthropic heeft hier Tool Search op de API geïntroduceerd: agents kunnen dynamisch tools selecteren op basis van de huidige taak zonder de volledige tool-lijst bij elk request mee te sturen.

```python
# Dynamische tool-selectie via Tool Search API
response = client.messages.create(
    model="claude-opus-4-8",
    tool_search={"query": "file operations and git"},  # selecteert relevante tools
    messages=[{"role": "user", "content": "Commit mijn wijzigingen"}]
)
```

Dit is fundamenteel voor schaalbare MCP-orchestratie: de agent weet welke tools bestaan (via search index), laadt alleen wat relevant is, en houdt de context vrij voor het eigenlijke werk.

**Stateless Streamable HTTP**

De productie-roadmap voor 2026 prioriteert stateless operatie achter load balancers. Huidige MCP-servers houden sessie-state bij per connectie, wat horizontale scaling praktisch onmogelijk maakt. De Streamable HTTP transport evolueert naar een stateless model waarbij requests over meerdere server-instances kunnen worden verdeeld.

Voor teams die MCP in productie willen draaien (in plaats van lokaal/development) is dit de blocker die wordt aangepakt. De bijbehorende enterprise features — audit observability, SSO-geïntegreerde auth ter vervanging van static client secrets, gateway patterns — vullen de resterende enterprise readiness gaps.

## OpenAI — GPT-5.5 Instant als nieuw standaard, deprecatie-kalender

GPT-5.5 Instant vervangt GPT-5.3 Instant als het standaardmodel voor ChatGPT en de API. De hallucination-reductie is het headline-getal: 52,5% minder gehallucineerde claims op high-stakes prompts, 37,3% minder op eerder gemarkeerde problematische gesprekken.

Op benchmarks: 81,2 op AIME 2025 (vs 65,4 voor GPT-5.3) en 76 op MMMU-Pro (vs 69,2). Gepositioneerd als OpenAI's equivalent van Claude Sonnet 4.6 in prijs/prestatie-verhouding — snel, goedkoop, frontier-nabij.

Relevanter voor de praktijk is de deprecatie-kalender:

| Model | Sunset datum |
|-------|-------------|
| GPT-5.2 | 12 juni 2026 (al voltooid) |
| GPT-4.5 | 27 juni 2026 |
| o3 | 26 augustus 2026 |

Als je API-code hebt die `o3` of `gpt-4.5` aanroept, heb je respectievelijk 6 dagen en 2 maanden om te migreren. De container billing-wijziging is ook opmerkelijk: per minuut gefactureerd met 5 minuten minimum (was een 20-minuut rate). Voor korte code-generatie containers kan dit een significante kostenbesparing zijn.

## AI Builders — Uber, SpaceX en de echte rekening van agentic coding

Simon Willison legt twee cijfers naast elkaar die samen iets vertellen over de huidige staat van AI-adoptie op enterprise schaal.

**Uber's budget in 4 maanden**

Uber heeft zijn volledige AI-budget voor 2026 al in april uitgeput. De response: een cap van $1.500/maand per medewerker per AI coding tool, inclusief Claude Code. Bij Fable 5's prijs van $50/MTok output kom je op circa 30 miljoen output tokens per maand per developer — wat neerkomt op intensief maar niet extreem gebruik in een agentic workflow.

Dit is geen anekdote. Het is een signaal over wat er gebeurt wanneer een grote engineering-organisatie agentic coding serieus neemt: de kosten schalen anders dan voor traditionele SaaS-tools. Per-seat pricing geeft een vals gevoel van voorspelbaarheid; token-spend in multi-agent runs kan in korte tijd non-lineair groeien.

**SpaceX en de rate limit-verdubbeling**

De tegenhanger: SpaceX heeft Cloud Services Agreements met Anthropic afgesloten voor $1,25 miljard per maand tot mei 2029. Anthropic gebruikte die compute-capaciteit om Claude Code rate limits te verdubbelen — inclusief de 5-uurs sessielimiet voor Pro/Max/Enterprise-accounts.

Voor langlopende Orion-workflows die tegen limieten aanliepen: dat speelruimte is er nu.

**Mercado Libre's 90%-target**

Mercado Libre (23.000 engineers) streeft naar 90% autonome coding met Claude Code voor Q3 2026. Dat is geen pilot — dat is een operationele transformatie op schaal. Als concrete benchmark voor wat agentic coding kan bereiken in een grote engineering-organisatie is dit het cijfer om bij te houden.

## Tot slot

De /cd command lijkt klein. Maar het verwijdert een frictie die dagelijks optrad bij iedereen die meerdere projecten in een monorepo beheert. Dat is het type feature dat je pas echt waardeert na een week gebruik — niet op het moment dat je de changelog leest.

En de Uber-cap van $1.500/maand is een nuttige kalibratie: zelfs zonder Fable 5 kan een team dat Claude Code intensief inzet snel tegen budgetgrenzen lopen. Actief token-monitoring is geen nice-to-have meer bij serieuze agentic setups — het is beheer.
