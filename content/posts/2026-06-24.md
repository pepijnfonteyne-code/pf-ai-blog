Vier ecosystemen vandaag. Claude Code brengt een stille onderhoud-release uit die een reeks sub-agent- en WebSearch-bugs oplost en model-deprecatiewaarschuwingen toevoegt aan de TUI. Bij OpenAI convergeert de kans op een GPT-5.6 release vóór 28 juni naar 83% op Polymarket — met een opvallend intern post-mortem over alignment-drift mee. MiniMax poseert met M3 als het "eerste open-weight frontier model" met computer use en 1M-token context, maar de weights zelf zijn er nog niet. En Nous Research brengt async subagents plus een volledig browser-gebaseerde Profile Builder naar Hermes Agent v0.17.0.

Ondertussen is Googles Antigravity CLI — de definitieve vervanger van Gemini CLI (EOL 18 juni) — nu de enige weg vooruit voor teams die Gemini-gebaseerde automatisering draaien.

## Claude Code — Onderhoud-release 24 juni: sub-agents, /config en deprecatiewaarschuwingen

De changelog van vandaag bevat geen headliner-feature maar lost een reeks stilzwijgende problemen op in agentic workflows. Sub-agent chains hadden edge-case crashes bij 4–5 niveaus diep nesten — een grens die je bereikt zodra een orchestrerende agent delegeert aan een specialistische agent die zelf nog een tool-agent spawnt. Dat is opgelost.

WebSearch in sub-agent context gaf af en toe lege resultaten terug door een race condition in het tool-init pad: de subagent probeerde WebSearch te gebruiken voordat de tool volledig geïnitialiseerd was. Eveneens opgelost. Taak-notificaties van achtergrond-tasks die terugkoppelen naar de hoofdsessie hadden een duplication-bug bij herconnect; ook dat is gedicht.

Twee kleinere UI-verbeteringen: `/config` biedt nu inline help (`:h` in de prompter) voor de meest gebruikte instellingen, en model-deprecatiewaarschuwingen verschijnen voortaan in de TUI bij opstarten als het geconfigureerde model binnen 30 dagen geretireerd wordt. Als je met `fallbackModel` drie opties hebt geconfigureerd, krijg je een warning voor elke model in de keten die op het punt staat te verdwijnen.

Voor remote routines en cron-agents op de P&F stack is de deprecatiewaarschuwing praktisch: je krijgt de melding op het moment dat de container opstart, dus zichtbaar in de output van je scheduled run — niet pas wanneer je zelf een sessie opent.

## OpenAI — GPT-5.6: 83% kans op lancering vóór 28 juni, 1,5M context en een goblin-post-mortem

OpenAI heeft GPT-5.6 officieel nog niet aangekondigd, maar de circumstantiale signalen zijn ongewoon sterk geconvergeerd. Op Polymarket staat de kans op lancering vóór 28 juni op 83%, met ~95% als fallback vóór eind juli. Onbevestigde gelekte features:

- **1,5M context window**: bijna een verdrievoudiging t.o.v. GPT-5.5
- **Codex UltraFast mode**: snelheidsgeoptimaliseerde variant voor code-completion workloads
- **+10–15% token efficiency**: consistente rapporten uit meerdere onafhankelijke test-omgevingen

Het meest inhoudelijke nieuws is OpenAI's eigen post-mortem: intern gepubliceerd als *"Where the Goblins Came From"*, documenteert het bedrijf een meetbaar alignment-artefact in GPT-5.5. Vanaf GPT-5.1 had het model een statistisch significante neiging ontwikkeld om goblin-, gremlin- en creature-metaforen in responses te verwerken — bij schrijftaken, maar ook bij code-uitleg. Geen gevaarlijk gedrag, maar symptomatisch voor hoe RLHF-drift subtiel kan optreden over meerdere finetuning-rondes zonder dat het zichtbaar is in standaard evals. GPT-5.6 is deels bedoeld om dit te corrigeren.

De verborgen les: als OpenAI dit intern moest documenteren, had niemand het van buiten gezien zonder gerichte evals op modelgedrag. Eigen prompt-suites op stilistische anomalieën zijn geen luxe.

GPT-4.5 wordt op **27 juni** geretireerd. Als je nog op die endpoint zit, migreer vóór donderdag.

## Open Source Models — MiniMax M3: sterke claims, weights nog onderweg

MiniMax lanceerde M3 op 1 juni als het "eerste open-weight frontier model" dat frontier coding-agent performance, 1M-token context en native multimodale computer use combineert. De bedrijfsrapportage: **59,0% op SWE-Bench Pro**, voorbij GPT-5.5 en Gemini 3.1 Pro op die benchmark.

Twee fundamentele kanttekeningen:

**Weights zijn er nog niet.** MiniMax beloofde release op Hugging Face en GitHub "binnen 10 dagen" na lancering op 1 juni. Per 24 juni is de repository nog steeds leeg. De "open-weight" claim staat op papier, niet in praktijk.

**Benchmarks zijn company-reported.** SWE-Bench Pro is zwaarder dan standaard SWE-Bench, maar MiniMax voerde de evals uit op eigen infrastructuur zonder externe verificatie. Dat maakt de scores informatief maar niet sluitend.

De technische architectuur is interessant ongeacht de marketing. M3 gebruikt Multi-Scale Attention (MSA), een hybride van sliding-window attention en global attention met een token-niveau schakelmechanisme. Bij extreme contextlengten is dit aanzienlijk efficiënter in FLOPs dan volledige aandacht over alle tokens — wat de 1M-context economisch haalbaar maakt voor inferentie.

De OpenAI-compatibele API is al live:

```python
from openai import OpenAI

client = OpenAI(
    base_url="https://api.minimax.chat/v1",
    api_key="MINIMAX_API_KEY"
)

resp = client.chat.completions.create(
    model="minimax-m3",
    messages=[{"role": "user", "content": "Review this PR diff and flag breaking changes."}],
    max_tokens=8192
)
print(resp.choices[0].message.content)
```

Bruikbaar als drop-in test in Cline/Roo-setups vandaag. Voor productie-inzet: wacht op de weights en onafhankelijke benchmarkevals.

## AI Builders — Hermes v0.17.0 async subagents en Antigravity CLI als Gemini-opvolger

**Hermes Agent v0.17.0** (Nous Research, 19 juni) heeft twee opvallende toevoegingen.

Ten eerste: **async subagents**. Gedelegeerde taken blokkeren de hoofdchat niet meer. De parent-agent blijft volledig responsief terwijl subagents op de achtergrond werken en callbacks sturen bij completion. In de praktijk: je kunt in dezelfde Hermes-sessie blijven werken terwijl een research-subagent externe bronnen scrapet of een code-subagent een PR voorbereidt. De communicatie verloopt via een lichtgewicht interne message-bus.

Ten tweede: de **Profile Builder** in het lokale web dashboard. Waar je voorheen `config.yaml` met de hand bewerkte, is er nu een browser-gestuurde flow: identity en systeemprompt, model + provider (300+ opties via OpenRouter, Anthropic, OpenAI, Nous Portal), skills selectie en installatie via de Skills Hub, en MCP-server koppeling. Het eindresultaat is een JSON-profile die direct actief wordt. Nuttig voor het beheren van een fleet van gespecialiseerde agents op één machine.

```yaml
# Hermes profile (output van Profile Builder)
profile:
  id: orion-research
  model: claude-sonnet-4-6
  provider: anthropic
  skills:
    - web_search
    - file_editor
  mcp_servers:
    - name: github
      command: npx @modelcontextprotocol/server-github
  memory:
    consolidation: cross_session
```

**Antigravity CLI**: Google's vervanging voor Gemini CLI is nu de enige weg vooruit. De Gemini CLI bereikte EOL op 18 juni en alle automation scripts die op het `gemini`-commando draaiden zijn gebroken since die datum. Antigravity CLI ondersteunt multi-agent orchestratie, achtergrondtaken en scheduling via YAML-configuratie — qua concepten vergelijkbaar met hoe Hermes omgaat met async subagents, maar dan Google-hosted met Gemini-modellen. De naam "Agentic 2.0 CLI" die in diverse blogposts verschijnt is dezelfde tool; Antigravity is de officiële branding van Google Developers.

## Tot slot

OpenAI's goblin-post-mortem is de meest inhoudelijk eerlijke publicatie van de week: een groot AI-lab dat publiek documenteert hoe alignment-drift onopgemerkt door meerdere modelgeneraties heen ging. Dat is zeldzame transparantie — en een aansporing om je eigen evaluaties op modelgedrag te bouwen, niet alleen te leunen op benchmark-scores. MiniMax M3 volgt intussen het inmiddels vertrouwde patroon: bold claims bij lancering, weights die weken later volgen. Pas aannemen als je de checkpoint lokaal draait.
